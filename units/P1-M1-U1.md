## Objective

Create the lean Xcode foundation for DropShot as a native macOS agent app.

## In scope

- Create the `DropShot.xcodeproj` app project and a `DropShotTests` target.
- Add `main.swift`, `Info.plist`, and a minimal `AppDelegate` that launches as an agent app.
- Add the smallest status item shell needed for the app to stay visible and quit cleanly.

## Non-goals

- Global hotkeys.
- Screen Recording permission flow.
- Screenshot capture or overlay UI.

## Completion contract

- `xcodebuild -list -project DropShot.xcodeproj` shows a buildable DropShot project and scheme.
- The app target builds as a macOS AppKit agent app.
- The shell is intentionally lean and does not include capture behavior yet.
