## Objective

Create the live capture session that gathers the image strips needed for stitching.

## In scope

- Start a scroll capture session from the selected region.
- Capture the initial strip immediately and additional strips from throttled scroll activity.
- Exclude DropShot overlay and HUD windows from the captured content.
- Stop the session from `Done`, `Cancel`, or `Esc`.

## Non-goals

- Final stitched image composition.
- Result preview.
- Quality heuristics beyond what raw strip collection requires.

## Completion contract

- A live session can collect ordered raw strips for one selected region.
- Session start and stop are owned by the coordinator and controller layer, not by ad hoc global state.
- The code is ready for a later stitching engine to consume those strips.
