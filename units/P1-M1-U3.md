## Objective

Make the app safe to launch and trigger before screenshot features exist by handling Screen Recording permission first.

## In scope

- Add a permission coordinator that preflights Screen Recording access.
- Show a minimal onboarding/settings handoff when permission is missing.
- Gate the capture entry path so later milestones can assume permission is already available.

## Non-goals

- Performing a real capture.
- Polling for live capture progress.
- Any other macOS permissions.

## Completion contract

- Capture entry returns early into the permission flow when Screen Recording is not granted.
- The permission UI is intentionally small and only explains the required setting.
- The app still builds with no live capture implementation yet.
