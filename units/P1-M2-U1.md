## Objective

Create the still-image capture primitive that the overlay flow will use.

## In scope

- Resolve the target screen from the current cursor position.
- Capture a single full-screen still image for that screen with ScreenCaptureKit.
- Return the image through `CaptureSessionCoordinator` in a form the overlay can present next.

## Non-goals

- Overlay windows.
- Region selection.
- Scroll capture or stitching.

## Completion contract

- The coordinator can request a still image for the active screen without involving any overlay UI yet.
- The capture path stays scoped to one screen and one image per trigger.
- The build remains green with no selection behavior added yet.
