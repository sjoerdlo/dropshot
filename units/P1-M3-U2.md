## Objective

Turn the frozen selection into a live scroll region the user can interact with underneath the overlay.

## In scope

- Add a live scroll mode to the selection overlay.
- Make the overlay visually transparent during that mode.
- Keep the selected region visibly outlined while the overlay window ignores pointer and scroll events.

## Non-goals

- Capturing or stitching scroll strips.
- Result output.
- Extra controls beyond the existing HUD.

## Completion contract

- The user can see the underlying app update live while the selected region stays clearly bounded.
- Input is passed through cleanly to the app below.
- The overlay remains usable as the visual frame for the later scroll session logic.
