## Objective

Implement the core algorithm that turns ordered strips into one tall image.

## In scope

- Add a `StitchingEngine` that ingests strips in order.
- Use `VNTranslationalImageRegistrationRequest` to detect vertical movement between adjacent strips.
- Append new content only when the movement is credible and vertically dominant.

## Non-goals

- UI changes.
- Horizontal stitching.
- Result window delivery.

## Completion contract

- The engine can accept the raw strip sequence and produce a composite image plus basic capture metadata.
- The algorithm stays explicitly vertical for V0.1.
- UI and session layers still remain outside this component.
