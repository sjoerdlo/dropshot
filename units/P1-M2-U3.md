## Objective

Let the user drag a capture region over the frozen overlay.

## In scope

- Add `SelectionOverlayView` with `idle`, `selecting`, and `selected` states.
- Support click-and-drag region creation and visible selection feedback.
- Return the final selected rect to the overlay controller and coordinator.

## Non-goals

- Scroll capture mode.
- Keyboard shortcut variations.
- Annotation or resize tooling beyond what the basic selection flow needs.

## Completion contract

- The user can drag a region on the frozen overlay and the app receives the final selected rect.
- The selection flow remains visually simple and scoped to V0.1 behavior.
- Later milestones can switch this selected region into live scroll mode without rewriting the selection state machine.
