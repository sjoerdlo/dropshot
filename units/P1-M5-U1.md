## Objective

Give the completed scroll capture a clear, minimal destination for the user.

## In scope

- Add a simple result window that presents the final image.
- Add `Copy` and `Save…` actions for that result.
- Let the coordinator present the result window when given a final image.

## Non-goals

- Auto-copy on completion.
- Screenshot history.
- Post-capture editing.

## Completion contract

- A final image can be shown in a minimal preview window.
- The user can copy or save from that window.
- Result delivery remains intentionally small and V0.1-specific.
